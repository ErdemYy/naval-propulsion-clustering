# Data Directory

This directory stores datasets according to standard data engineering conventions:

- `raw/`: Stores pristine, immutable raw data as obtained from official sources (e.g., UCI Machine Learning Repository). Never modify files in this directory.
- `processed/`: Stores cleaned, imputed, filtered, or transformed datasets generated by reproducible data preparation scripts.

### Target Isolation Notice:
Features and degradation targets ($kMc$, $kMt$) will be handled separately by the pipeline loaders in `src/naval_propulsion/data/loader.py`.
Raw data is excluded from git version control via `.gitignore`.
